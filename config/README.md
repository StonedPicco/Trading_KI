# config/

`alpaca.env` wird beim ersten Start von `Start.bat` / `start.sh` angelegt und enthält eure
Alpaca-Keys. Die Datei ist per `.gitignore` ausgeschlossen und landet nie auf GitHub.

Keys ändern: Datei mit einem Texteditor öffnen oder löschen; beim nächsten Start wird erneut gefragt.
Bleiben die Felder leer, läuft die Plattform im klar gekennzeichneten DEMO-Modus.
